Strings
A  string represent group of characterString written in java are all String class objectsString class objects are immutable(can not be modified)because time taken by the JVM to reallocate memory and add data to an existing object is more than the time taken to create a new objectJava defines the string class which is part of the  java.lang  package.C, C++ implement String as a character array where as in Java  Character Array and String are different

=== Slide 7 of 9 ===
StringBuffer ClassAn object of String class is immutableIn order to achieve mutability java provide a class call StringBufferWhen ever + (concatination) operator is used on String objects , the string object will changed into an instance of StringBuffer and its  append() method is called on that instance of StringBuffer. After that StringBuffer is changed into String by using toString()     method of the Object class StringBuffer also facilitates the insertion of a character in the middle of the string
