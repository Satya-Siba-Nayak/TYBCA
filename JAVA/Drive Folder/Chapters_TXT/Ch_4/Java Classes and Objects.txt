Creation of a Class object
A class shall be viewed as a short template for an objectA class object is the single instance of a class that retain the structure  and behavior of the classClass is a user defined data type.We can declare the variable of this user defined class  called objects or instance of the class.The process of creating new object called as instantiation.E.g		Rectangle r1 = new Rectangle ( ) ; Here the variable r1 called as object variable . It stores the location of the new object or reference of the new objectIn Java Every value is either primitive data type value(int ,double,       boolean, and char) or an object reference .

Constructor
Java  provides  a special concept called as Constructor for creating  an   object of a class and initializing its instance variable.Name of constructor method should be same as class name.It is generally declared as public.It does not have a return type , not even void.Constructors are not a methodsWe cannot invoke constructor on existing objectWe  can  only use / invoke  constructor  only in  combination  with new operator.If the constructor are not define in the class , then the Java compiler        automatically generate and execute a constructor that   has no argument Such constructor called as default constructor
